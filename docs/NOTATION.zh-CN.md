# 记号与约定

| 记号 | 含义 |
| --- | --- |
| $B=|Q_B|$ | 经典坐标对称群的阶，沿指定无限序列增长 |
| $C_B\subseteq\mathbb F_2^{L_B}$ | 构造群时使用的经典码，不是局部鲁棒码 |
| $A_B=C_B^*$、$s_B$、$M$ | 代数对偶、经典码维数、$2^{s_B}$ |
| $K$、$b$ | 固定标签群、$|Q_B\times K|$ |
| $P'_B$、$\Lambda_B$ | 半直积群及零和公共坐标子群 |
| $X_B$、$N$ | 左陪集空间及其大小 $Mb^3$ |
| $\mathcal X$ | flagged 四维立方复形，与基点集合 $X_B$ 不同 |
| $\eta$ | 方向分量比例 $b^{-2}$，不是单个分量内部的谱隙 |
| $D$、$q=2^\ell$ | 固定方向度数和固定系数域 |
| $h_i$、$r_i$ | 局部满行秩校验矩阵及其行数；列由生成元标签编号 |
| $\kappa$、$\lambda$、$\gamma$ | 局部鲁棒常数、非平凡绝对谱界、正转移余量 |
| $c_j$ | $\mathbb F_q$ 上链空间维数，不是二元维数 |
| $B_j$ | $\partial_j$ 的二元展开矩阵，与族参数 $B$ 区分 |
| $n,k,m$ | 物理量子比特数、逻辑比特数、实际列出校验数 |
| $d_X,d_Z$ | 两个逻辑扇区的最小非零逻辑代表重量 |
| $\rho$ | 对全部 Pauli 误差的归一化全局 tester soundness |
| $\mathsf D$ | 按 syndrome 最小 Pauli 重量对角化的距离 observable |

矩阵作用在列向量上。群律为 $(a,g)(a',g')=(a+g a',gg')$；陪集使用左乘作用。二元 CSS 使用先二元化再转置的 $H_X=B_2,H_Z=B_3^T$。Pauli 重量取两个支撑的并集；冗余校验保留。所有渐近常数均与 $B$ 无关；局部常数可以很大。

Lean 草稿里局部正率参数使用 $\nu=1/100$，本文用 $\nu=1/32$ 举例。两者都属于允许区间，但不能据此声称草稿已经验证本文全部选择。
