# 来源、保留和编辑边界

本仓库从用户提供的研究档案、四维 Lean 尝试包和四维数学核验包整理而来。[inputs.json](inputs.json) 记录输入文件名、大小、SHA-256 及主要变换；它不声称这些输入经过独立同行评审。

本次只保留 $t=4,j=2$ 的证明路线和相应有限实验。未打包其他维数的端点研究、原始对话、第三方全文论文、无关大矩阵或运行缓存。正文以此前数学核验稿为底本，补写实际立方 incidence、统一符号、改为 GitHub 可渲染公式和相对链接，并更正固定文献版本的作者次序和标题元数据。没有把此前的数学审查描述成此次又进行了一轮独立审查。

两个有限程序保留原构造与精确运算。发布整理增加了 CLI 输出路径、输入校验、四维范围限制和断言启用检查。基准去掉非确定的耗时字段，结构性值未更改。新增包装脚本、单元测试、文档和 CI 是本次整理工作。

`.lean` 证明内容没有修改；其身份清单在 [lean_source_hashes.json](lean_source_hashes.json)。先前构建未启动的记录位于 [lean_attempt](lean_attempt/status.json)，记录中的绝对工作目录被归一化，但失败原因与验证状态未改变。该历史记录不应被当成本次通过验证的证据。

本次实际运行的结果位于 [packaging_run](../verification/packaging_run/summary.json)。没有创建远端仓库、上传 GitHub、作出署名或许可证选择。数学正确性、文件完整性、有限测试通过与完整形式化是相互区分的事项。
